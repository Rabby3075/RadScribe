# Licences And Data Source Notes

Last checked: 2026-08-21

## Indiana University Chest X-ray Collection

This project uses the Indiana University Chest X-ray Collection from Open-i / NLM, with the local Kaggle-style files:

- `data/indiana_reports.csv`
- `data/indiana_projections.csv`
- `data/images/images_normalized/`

Useful source pages:

- Open-i FAQ: https://openi-vip.nlm.nih.gov/faq
- Open-i main site: https://openi.nlm.nih.gov/
- Kaggle-style mirror commonly used for this dataset: https://www.kaggle.com/datasets/raddar/chest-xrays-indiana-university

The Open-i FAQ says reuse depends on the image licence and asks researchers not to share the dataset outside their group or organization. Common mirrors list the dataset as Creative Commons Attribution-NonCommercial-NoDerivatives 4.0 International.

For this portfolio project, the raw images are not committed to git. The project keeps only scripts, documentation, and small processed metadata files.

## Project Usage Rule

This project is for learning and portfolio use only. It is not for clinical use and not for diagnosis.
